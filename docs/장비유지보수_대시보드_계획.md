# 장비 유지보수 CSV 시각화 대시보드 계획

## Summary

`실습자료들/장비유지보수_2022-2024.csv`를 사용해 설치 없이 바로 열 수 있는 단일 HTML 대시보드를 만든다. CSV 데이터는 HTML 내부 JavaScript에 내장해 로컬 브라우저 보안 문제 없이 실행되게 한다.

대시보드 주제는 "설비 유지보수 비용과 고장 원인을 한눈에 보는 운영 현황판"으로 잡는다. 데이터는 229행, 기간은 2022-01-05부터 2024-12-31까지이며, 총 비용 68,233,000원, 평균 수리시간 2.93시간, 부품교체율 34.9%를 핵심 KPI로 사용한다.

## Key Changes

- `실습자료들/장비유지보수_대시보드.html` 단일 파일을 생성한다.
- CSV 원본은 수정하지 않고, 구현 시 CSV를 읽어 HTML 내부의 `const maintenanceData = [...]` 형태로 변환해 내장한다.
- 화면 구성:
  - 상단 KPI: 총 유지보수 비용, 총 건수, 평균 수리시간, 부품교체율
  - 월별 추이: 월별 비용과 건수
  - 원인 분석: 이상유형 Top 목록 또는 막대 차트
  - 설비 분석: 비용 상위 장비
  - 위치 분석: 설치위치별 건수
  - 상세 테이블: 날짜, 장비명, 위치, 이상유형, 수리시간, 비용, 부품교체여부
- 인터랙션:
  - 연도 필터: 전체, 2022, 2023, 2024
  - 설치위치 필터
  - 이상유형 필터
  - 필터 변경 시 KPI, 차트, 테이블을 모두 재계산한다.
- 시각 스타일은 제조/운영 대시보드답게 차분하고 실무적인 톤으로 구성한다. 과한 랜딩페이지나 장식적 hero는 만들지 않는다.

## Interfaces

- 외부 서버, npm, Python 실행 없이 HTML 파일만 브라우저에서 연다.
- 외부 라이브러리 없이 순수 HTML/CSS/JavaScript와 SVG 기반 차트로 구현한다.
- 공개 API나 별도 데이터 스키마는 만들지 않는다.
- 원본 CSV 파일명과 위치는 그대로 유지한다.

## Test Plan

- HTML 파일을 브라우저에서 열어 첫 화면이 비어 있지 않고 KPI 값이 표시되는지 확인한다.
- 전체 데이터 기준 KPI가 원본 집계와 맞는지 확인한다:
  - 총 건수 229
  - 총 비용 68,233,000원
  - 평균 수리시간 약 2.93시간
  - 부품교체율 약 34.9%
- 연도/위치/이상유형 필터를 바꿨을 때 KPI, 차트, 상세 테이블이 함께 갱신되는지 확인한다.
- 모바일 폭에서도 카드, 차트, 테이블이 겹치지 않고 읽히는지 확인한다.
- 원본 CSV가 수정되지 않았는지 확인한다.

## Assumptions

- 사용자가 선택한 방향은 `장비유지보수_2022-2024.csv`, 단일 HTML, 데이터 내장 방식이다.
- 대시보드 산출물은 실습용 결과물이므로 배포 서버나 계정 인증은 범위 밖이다.
- CSV 변경분을 자동 반영하는 기능은 이번 버전에서 제외한다. 새 CSV를 반영하려면 HTML을 다시 생성하는 방식으로 처리한다.
